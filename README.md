# Portfolio - Loïc Mennessier

Un portfolio pour présenter mes projets, mes compétences et mon parcours : Master MIAGE, développeur Full Stack en alternance chez OCAPIAT.

Le design suit l'idée d'une ligne de métro : chaque étape du parcours et chaque projet est une station.

## 🚀 Technologies Utilisées

* **Front-End :** React, Vite, Tailwind CSS
* **Animations :** Framer Motion
* **Typographie :** Overpass (auto-hébergée via Fontsource)
* **Composants & Design :** SVG personnalisés et React Icons

## Lancer le projet

```bash
npm install
npm run dev
```
